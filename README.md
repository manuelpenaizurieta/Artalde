# Artalde · Idiazabal DOP

Prototipo de tienda online **ficticia** para un trabajo académico del Máster GESCO de ESIC (asignatura Comunicación y Omnicanalidad).

Artalde es una marca inventada. En esta web:
- no se vende nada;
- no se cobra nada;
- no se envía ningún dato personal a ningún servidor. Lo único que se carga de fuera son las fuentes de Google Fonts.

Todo lo que se escribe se queda en el navegador de quien la usa.

- **Web:** `index.html`, un único archivo con las 26 páginas en alemán, inglés y español, más el mini CRM.
- **Cuenta de clienta:** `demo@artalde.example`, contraseña `Esic123`.
- **Mini CRM (administración):** `admin@artalde.example`, contraseña `Esic123`.
- **Códigos de degustación de prueba:** `ART-2027-BJRN`, `ART-2027-KTHR`.

Los correos usan el dominio reservado `.example` para que ninguno coincida con un buzón real.
